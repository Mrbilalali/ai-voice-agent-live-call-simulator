# AI Voice Agent — Live Call Simulator

Interactive, scripted demo of an AI voice agent handling a simulated inbound call for the
fictional "Demo Dental Co." — pick one of three caller intents, watch the live transcript
with intent/entity/sentiment detection chips, and see the call end in a booked appointment
plus a confirmation-SMS preview.

**Live demo:** https://ai-voice-agent-live-call-simulator-mr-bilal-alis-projects.vercel.app

**What it shows:** inbound-call voice AI → live transcript → intent detection → qualification →
appointment booked — reaching the payoff in under 90 seconds, then a booking CTA.

**Honest framing:** clearly labeled throughout as a *scripted simulation* of a fictional
business. It places no real calls and sends no real SMS. No real client names, numbers, or
results are used or implied.
